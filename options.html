读懂世界，写出自己的话。

在 X 页面直接使用

点击帖子下的「翻译／回复」打开并排侧栏：自动翻译、查词、讲解、收藏，或用中文想法生成跨语言回复。关闭后右下角小把手可再打开。

打开自由写作工作台 ↗独立长文页面：草稿自动保存、参考文章学习、分层反馈
阅读页的译文语言单独设置，英文原文默认译成中文。

交互翻译优先选择 Flash／低延迟模型。较慢的推理模型可能明显增加等待时间；模型由你选择。

OpenAI 兼容地址；以 https:// 开头
填写服务商提供的准确模型名，支持 /；不会自动替换你的选择。
自动模式下，进入帖子或文章详情时，正文会发往所选模型；手动模式下点击翻译才发送，可能消耗你的模型额度；点击生成、检查或讲解时也会发送相应上下文与输入。OpenAI 请求设为 store: false；其他服务商的留存规则以其说明为准。密钥仅保存在此浏览器的扩展本地存储，不会同步或写入 X。

开启后，附近帖子文字与规则会直接发往 TypeSafe，包括你能看到的受保护账号帖子。插件无中转服务器；命中后仍可展开。

存下能再次使用的表达

句型、结构和词语只保存在本机。点击原帖链接可回到语境。

取词不必用大模型

按「本地词表 → 本地 MDX 词典 → 在线」的顺序查词；在线查询会把单词发给 MyMemory 与 Free Dictionary API。

尚未导入本地词表

支持 TSV、CSV 或 JSON，格式为“单词 + 释义”。导入新文件会替换旧词表。

本地 MDX 词典（离线）

导入 MDict .mdx（如 LDOCE5）后完全离线查词；重新导入时旧词库全程可查（原子切换）。大词典建议点按钮在独立标签页导入——弹窗关闭不会中断。

MDX 解析与索引全部在本机 IndexedDB 完成，词库文件不上传、不进安装包、不发给模型。在线兜底查询会把单词发送给 MyMemory 与 Free Dictionary API。你提供的 `.eubak` 只是指向 `.mdx` 的配置，本身不含词条。

本地数据与迁移

导出设置、草稿、练习、收藏和学习记录，含 Markdown 文稿与 Agent 历史，不含 API 密钥、服务密码或 OpenCode 远端会话 ID。MDX 词典需用原文件重新导入。
