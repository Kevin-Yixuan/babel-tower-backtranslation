# 0.4.0 体验改版

本轮从 0.3.1 的已集成源码继续迭代，目标是让用户知道从哪里开始、在哪里配置，以及怎样在较窄的窗口里继续写作。

## 设计决定

- 弹窗直接提供「去 X 阅读与回复」和「自由写作台」两个入口，设置放在次级位置。首次连接模型的提示与操作入口放在一起。
- 设置页按任务拆为模型连接、阅读与回复、写作助手、离线词典、收藏表达、数据与备份、实验功能。桌面使用左侧导航，窄窗口使用可滚动的横向导航。备份与历史不再出现在每个设置区的末尾。
- 设置使用持续可见的全局保存栏。切换功能区保留未保存输入，保存动作仍通过同一个生产接口提交完整配置。状态提示在任意功能区可见。
- 写作台统一使用浅纸色、深绿强调。文稿库、编辑器和助手在宽窗口并排，在窄窗口改为可开关的抽屉；切换抽屉不重建文稿或聊天。抽屉顶部跟随工具栏实际高度，Escape 关闭并恢复入口焦点。
- X 侧栏保留六个功能入口与原有数据协议；导航不换行，支持方向键、Home、End，Escape 关闭侧栏。页签具有可读的选中状态与内容关联。

## 验证范围

新增 `tests/redesign-smoke.cjs` 验证真实 MV3 扩展页面中的跨区配置保存、刷新恢复、七个设置区、窄窗口工具栏、抽屉切换后草稿保留、侧栏键盘导航与焦点恢复。加入标准浏览器测试入口。

原有历史与备份回归改为先进入「数据与备份」，保持原来的分页、复制、冲突与部分失败断言。发布仍使用白名单构建和 ZIP 内容校验；截图、测试配置和词典文件不进入安装包。

测试使用隔离 Edge、本地模拟 X 页面和受控响应。真实登录态 X、真实模型及本机 Pi 的端到端行为仍需实用验证。
