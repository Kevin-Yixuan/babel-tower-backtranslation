# 回译体验迭代验收规格

用户于 2026-09-26 确认。实施起点：`7b069c0dbf6a8d6c8939dc54cca72b9b6a613f9d`；历史比较基线：`860c196e8aafebdcf8062aff1ad5d32fd78e2f39`。

## 第一轮：阅读到回复

- 同一帖子在作者链接、`/i/status/ID`、查询参数和 X/Twitter 域名形式下使用同一稳定身份。插入仍须预览、确认时重新检查原帖及编辑框归属；跨帖、未知目标、全局发帖框不得写入，不自动发布。
- 新划选和新输入优先于异步历史恢复。快速 A→B→A、恢复中切帖及晚到模型响应不串内容，不丢未发送稿件。
- 全文、划选、手动三种取材模式，以及未提交手动原稿、语言方向、已有译文按帖保存；回帖和刷新后恢复。新帖默认全文，旧会话缺字段兼容读取，不清空旧数据。
- 手动和全文共用明确的翻译入口；显示取材、语言、处理/停止/失败状态。重试仅处理失败段落，成功段保留。停止后不继续排队、不应用旧响应；不承诺撤销已发请求的计费。
- 保留回复的完整可编辑草稿、中文回译、意思风险、具体改法、后续建议，以及候选采用/忽略与复制兜底。用户改稿不得被模型覆盖，中文 IME 组合输入不中断。
- 悬停与划词使用同一词界规则，以原划词行为为基准，覆盖数字、连字符、弯引号及跨内联元素。

## 第二轮：配置到恢复

- 区分当前生效配置与未保存表单。切换配置保留输入，保存成功才生效，失败保留原配置与输入并允许重试；避免重复保存，只有未保存修改时离开/刷新才提示。
- 连接测试绑定发起时的配置与表单版本；切换或编辑后晚到结果不串台。测试不保存配置，提示和日志不回显密钥。
- 历史列表显示摘要、更新时间与冲突标记，支持搜索、最近 20 条及显示更多。普通记录能返回原帖和复制草稿；冲突副本可查看/复制，不自动覆盖原记录。原始 JSON 折叠为技术详情，删除前确认并提示备份。
- 保持备份格式和合并策略：记录冲突另存，同名词条/偏好/已有提示词优先本地；预览和实际结果显示导入、跳过、另存数量。部分成功准确报告范围。密钥不迁移，MDX 使用原文件重新导入。

## 接口、结构和验收证据

- 保持 `SESSION`、`BACKUP` 现有操作兼容，可增补阅读快照字段和备份统计。会话字段定义单一来源，兼容普通内容脚本和 MV3 后台。
- 设置保存逻辑集中于现有 settings module，测试走真实生产逻辑/消息链路，不复刻后台实现；仅替代外部网络、浏览器和存储故障等系统接口。
- 保留原生 JavaScript、无构建加载方式、配色和主要布局。不增加框架、不改发布渠道、不创建公开 Release、不替换日用安装目录。
- 每个缺陷须有失败→修复→通过证据；新增测试进入标准入口。必需命令为 `npm test`、`node --test tests/packaging.test.mjs`、`npm run test:browser`。
- 浏览器验收在包含候选改动的隔离副本运行，保护已有截图与三个用户 `tests/zdebug-*.cjs`。构建校验 preview/store 本地候选包，至少从最终 ZIP 解压后加载验证。
- 最后由 Astra 独立核验冻结提交和包哈希，分别报告 Standards 和 Spec。Node、隔离浏览器、真实 X、真实模型的证据分别说明；未执行的检查不得声称通过。
